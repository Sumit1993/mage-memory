# Distractor project rules (task-irrelevant, identical across arms)
- Use 2-space indentation in every JSON, YAML and JavaScript file.
- Docker images pin a digest, never the `latest` tag.
- Never log secrets, tokens or full card numbers.
- Name boolean variables with an `is`, `has` or `should` prefix.
- Public HTTP endpoints are documented in `docs/api/` with a request and response example.
- Database migrations are forward-only and each one is reversible by a follow-up migration.
- Use CSS custom properties for colours and spacing; no hard-coded hex values in components.
- Pull requests stay under 400 changed lines where possible.
- Paginate list endpoints with a `cursor` parameter and a default page size of 50.
- Prefer `const` over `let`; never use `var`.
- Every service exposes `/healthz` returning 200 with a JSON body.
- Read credentials from environment variables, never from committed files.
- Use kebab-case for file names, camelCase for functions, PascalCase for classes.
- Architecture decisions go in `docs/adr/` using the numbered template.
- Add an index in the same migration that introduces a foreign key.
- Every interactive element must be reachable by keyboard and have a visible focus state.
- Request review from the code owner of the touched folder.
- Return RFC 7807 problem documents for HTTP errors.
- Limit lines to 100 characters except for URLs and import lists.
- Kubernetes manifests set CPU and memory requests and limits on every container.
- Hash passwords with argon2id; never use MD5 or SHA-1 for anything security related.
- Name environment variables in SCREAMING_SNAKE_CASE with a `SHOP_` prefix.
- Write documentation in the second person and present tense.
- Never run `SELECT *` in application code; list the columns.
- Images need `alt` text; decorative images use an empty `alt`.
- Squash-merge feature branches; keep the merge title in imperative mood.
- Version public endpoints in the URL path as `/v1/`.
- Use single quotes in JavaScript strings, double quotes in JSON.
- Deployments to production happen only on weekdays before 15:00 UTC.
- Set `HttpOnly` and `Secure` on every session cookie.
- Name database tables in plural snake_case and columns in singular snake_case.
- Diagrams use Mermaid fenced blocks, never pasted images.
- Wrap multi-statement writes in a transaction.
- Prefer CSS grid for page layout and flexbox for one-dimensional rows.
- Tag releases with semantic versions prefixed by `v`.
- Timeouts on outbound HTTP calls are 5 seconds unless the integration doc says otherwise.
- Sort import statements alphabetically within each group.
- Roll back a failed deploy before investigating it.
- Validate all inbound HTTP payloads with a schema before use.
- Name feature branches `feat/<short-slug>` and fixes `fix/<short-slug>`.
- Each service folder keeps a short README with an owner and an on-call contact.
- Store timestamps in UTC as `timestamptz`.
- Keep React components under 200 lines and split when they grow past it.
- Close stale branches after 30 days without activity.
- Retry outbound calls at most 3 times with exponential backoff and jitter.
- End every file with exactly one trailing newline.
- Log in JSON lines with a `level`, `ts` and `service` field in deployed services.
- Pin third-party GitHub Actions to a full commit SHA.
- Prefix private helper functions with an underscore.
- Link to an existing doc instead of copying its text.
