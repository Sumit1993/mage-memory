# Thresholds

The numbers mage uses are defined in one place in the code, so nothing scatters
and nothing drifts. The table below is generated from that source (via
`pnpm docs:gen`) and guarded by a drift test, so it always matches the running code.

<ThresholdsTable />

## What 0.0.18 uses

- `noteSizeCap` — the authored-note body byte cap; memory-genre notes exceeding
  it are annotated by `mage doctor` (info level; read-only, nothing blocks).
- `rewordRate` and `demoteRate` — the context-match rates below which a
  generated wing skill is flagged for reword or demote.
- `minLoads` — the minimum number of times a skill must auto-load before
  context-match is allowed to judge it, so no verdict rests on thin evidence.
- `editBudget` — the most edits the optimize pass applies per run, so a skill
  never thrashes. See [Optimize](../loop/optimize.md).

## Rows that gate nothing

The recurrence gates K and M, the sensitivity dial that scaled them and the
staging, promotion and lesson budgets belonged to the loop that 0.0.18 cut from
the surface ([ADR-0060](https://github.com/Sumit1993/mage-memory/blob/main/mage/decisions/0060-the-ladder-reset.md)).
Their rows stay in the table because the code stays until #223 removes it. No
verb you can run reads them.

For the ladder itself, see [The ladder](../loop/overview.md). For the CLI surface,
see the [Commands reference](../reference/commands.mdx).
